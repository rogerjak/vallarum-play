# Vallarum – Sista skörden

Senaste Windowsversionen är **v0.9.4**. [Hämta spelet](https://github.com/rogerjak/vallarum-play/releases/tag/v0.9.4).

Packa upp hela ZIP-filen och starta Vallarum.exe. Unity behöver inte installeras.

Nyheter i 0.9.4: en bevakande fågelskrämma, strömavbrott och reservkraft, förrymda grisar, Vallarumsradions förutsägelser, förberedelser inför sista försvaret och Zeus upptäcktsspår. Tydligare interaktioner, dialogprioritet, belysning och markdetaljer.

Webbversionen är pausad tills vidare eftersom den inte är testad för v0.9.4. Denna release gäller Windows.

[Nedladdningssida](https://rogerjak.github.io/vallarum-play/) · [Källor och krediter](CREDITS.md).

Detta repo innehåller endast offentlig distribution, inte projektets källkod.
