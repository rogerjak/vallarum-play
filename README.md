# Vallarum – Sista skörden

Senaste Windowsversionen är **v0.9.8**. [Hämta spelet](https://github.com/rogerjak/vallarum-play/releases/tag/v0.9.8).

Packa upp hela ZIP-filen och starta Vallarum.exe. Unity behöver inte installeras.

Nyheter i 0.9.8: Varmare träskaft på högrepen, förbättrade tunnmaterial och en ny fraktlåda. Rättade projektilträffar och skydd bakom väggar, säker återstart under låga tak samt tydligare meddelanden vid sparning.

Webbversionen är pausad tills vidare eftersom den inte är testad för v0.9.8. Denna release gäller Windows.

[Nedladdningssida](https://rogerjak.github.io/vallarum-play/) · [Källor och krediter](CREDITS.md).

Detta repo innehåller endast offentlig distribution, inte projektets källkod.
