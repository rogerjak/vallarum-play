# Vallarum – Sista skörden

Senaste Windowsversionen är **v0.9.6**. [Hämta spelet](https://github.com/rogerjak/vallarum-play/releases/tag/v0.9.6).

Packa upp hela ZIP-filen och starta Vallarum.exe. Unity behöver inte installeras.

Nyheter i 0.9.6: Frivillig potatisgolf, tydligare mål och övergångar i kampanjens sju uppdrag samt förbättrad färggradering, nattläsbarhet, skördestubb och material på potatiskanon och grisfålla.

Webbversionen är pausad tills vidare eftersom den inte är testad för v0.9.6. Denna release gäller Windows.

[Nedladdningssida](https://rogerjak.github.io/vallarum-play/) · [Källor och krediter](CREDITS.md).

Detta repo innehåller endast offentlig distribution, inte projektets källkod.
