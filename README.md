# Vallarum – Sista skörden

Senaste Windowsversionen är **v0.9.2**. [Hämta spelet](https://github.com/rogerjak/vallarum-play/releases/tag/v0.9.2).

Packa upp hela ZIP-filen och starta Vallarum.exe. Unity behöver inte installeras.

Nyheter i 0.9.2: Äggtvätten och Nattpasset utökar kampanjen till sex uppdrag. Hängande djurkroppar, bloddroppar och nattvakter i stallarna, EPA-trafik, förbättrade vattenpassager och ett nytt skördefirande.

Webbversionen är pausad tills vidare eftersom den inte är testad för v0.9.2. Denna release gäller Windows.

[Nedladdningssida](https://rogerjak.github.io/vallarum-play/) · [Källor och krediter](CREDITS.md).

Detta repo innehåller endast offentlig distribution, inte projektets källkod.
