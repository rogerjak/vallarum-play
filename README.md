# Vallarum – Sista skörden

Senaste Windowsversionen är **v0.9.9**. [Hämta spelet](https://github.com/rogerjak/vallarum-play/releases/tag/v0.9.9).

Packa upp hela ZIP-filen och starta Vallarum.exe. Unity behöver inte installeras.

En kort skräckinledning öppnar **v0.9.9** på Elldala. En gul pil på kompassen och minikartan leder dig från köksdörren till nästa delmål. Tryck **Tab** för att växla instrument och **M** för att öppna den stora kartan. Efter sista skörden får du höra gårdens bokslut i radion.

Webbversionen är pausad tills vidare. Den här utgåvan finns för Windows.
