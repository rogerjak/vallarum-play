# Vallarum – Sista skörden

Senaste Windowsversionen är **v0.9.7**. [Hämta spelet](https://github.com/rogerjak/vallarum-play/releases/tag/v0.9.7).

Packa upp hela ZIP-filen och starta Vallarum.exe. Unity behöver inte installeras.

Nyheter i 0.9.7: Rättade vita ljusfläckar vid händer och vapen, betydligt lägre däcksladdljud på traktorn och en mjuk kapitelövergång som förklarar tidshoppet till Nattpasset.

Webbversionen är pausad tills vidare eftersom den inte är testad för v0.9.7. Denna release gäller Windows.

[Nedladdningssida](https://rogerjak.github.io/vallarum-play/) · [Källor och krediter](CREDITS.md).

Detta repo innehåller endast offentlig distribution, inte projektets källkod.
