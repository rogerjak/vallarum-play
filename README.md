# Vallarum – Sista skörden

Senaste Windowsversionen är **v0.9.5**. [Hämta spelet](https://github.com/rogerjak/vallarum-play/releases/tag/v0.9.5).

Packa upp hela ZIP-filen och starta Vallarum.exe. Unity behöver inte installeras.

Nyheter i 0.9.5: Tomtelands julverkstad och modellkällare med animerade detaljer och en sittande tomte, förbättrade gårdsmiljöer och vegetation, tydligare menyer och HUD samt ljussatta vägskyltar och nya gatlampor.

Webbversionen är pausad tills vidare eftersom den inte är testad för v0.9.5. Denna release gäller Windows.

[Nedladdningssida](https://rogerjak.github.io/vallarum-play/) · [Källor och krediter](CREDITS.md).

Detta repo innehåller endast offentlig distribution, inte projektets källkod.
