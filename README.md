# Vallarum – Sista skörden

Senaste Windowsversionen är **v0.9.1**. [Hämta spelet](https://github.com/rogerjak/vallarum-play/releases/tag/v0.9.1).

Packa upp hela ZIP-filen och starta Vallarum.exe. Unity behöver inte installeras.

Nyheter i 0.9.1: Rörliga sädesmotiv, tydligare falska steg och radiofragment, ett gårdsfönster som slocknar, ryckigare halmdockor och rättade trädmaterial.

Webbversionen är pausad tills vidare eftersom den inte är testad för v0.9.1. Denna release gäller Windows.

[Nedladdningssida](https://rogerjak.github.io/vallarum-play/) · [Källor och krediter](CREDITS.md).

Detta repo innehåller endast offentlig distribution, inte projektets källkod.
