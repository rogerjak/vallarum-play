# Vallarum – Sista skörden

Senaste Windowsversionen är **v0.9.3**. [Hämta spelet](https://github.com/rogerjak/vallarum-play/releases/tag/v0.9.3).

Packa upp hela ZIP-filen och starta Vallarum.exe. Unity behöver inte installeras.

Nyheter i 0.9.3: Sägenstenarnas viskningar och uppenbarelser, omarbetade djurmodeller och lugnare skräcktempo i Nattpasset. Tydligare gårdsytor, djupare ladfönster, bättre arbetsljus och rättad hälsovisning.

Webbversionen är pausad tills vidare eftersom den inte är testad för v0.9.3. Denna release gäller Windows.

[Nedladdningssida](https://rogerjak.github.io/vallarum-play/) · [Källor och krediter](CREDITS.md).

Detta repo innehåller endast offentlig distribution, inte projektets källkod.
